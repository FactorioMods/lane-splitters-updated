# Lane Splitters: Updated

Makes the native lane splitter available to build and adds fast, express and, with Space Age, turbo variants. Choose a tier to match the surrounding belt speed.

This continuation updates the original entity, recipe and technology definitions for Factorio 2.1 while retaining their existing names for saves and blueprints.

Requires Factorio 2.1.24 or newer. The supplied tiers follow the vanilla belt families. Additional belt tiers from other mods need their own compatible definitions.
